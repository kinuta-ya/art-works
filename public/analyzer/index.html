発振器（テスト信号）

最初は小さい音量から。イヤホンを耳から外し、測定器具（カプラー）に付けた状態で鳴らしてください。

保存した曲線

ピーク保持がONのときはピーク曲線を、OFFのときは現在の曲線を保存します。

    使い方と測定のしかた

    基本（1ch・マイクのみ）

    1. イヤホンを測定器具（カプラー：イヤホンとマイクを密着させる筒など）に取り付けます。
    2. 「開始」を押してマイクを許可します。
    3. 発振器でピンクノイズを鳴らし、平均化「遅い」か「累積」にすると安定した特性が出ます。
    4. スイープ＋「ピーク保持」でも測れます。1〜2往復ぶん鳴らすと線が描き上がります。
    5. 名前を付けて「保存」すると、別のイヤホンと重ねて比べられます。

    iPhoneでは、有線やBluetoothのイヤホンをつなぐと入力がイヤホン側のマイクに切り替わる場合があります。 その場合は、別の端末（PCなど）で信号を鳴らし、iPhoneで測る方法が確実です。

    2ch（基準付き）— USBオーディオインターフェースを使う方法

    • インターフェースの入力1にマイク、入力2に出力信号をケーブルで戻します（ループバック）。
    • 「2ch（基準付き）」を選ぶと、マイクの音 ÷ 出力信号 を表示します。信号の偏りや再生機器の癖が打ち消され、イヤホン（＋マイク）の特性だけが残ります。
    • 電気回路そのもの（ネットワークのコンデンサー・抵抗など）を測るときは、出力 → 回路 → 入力1、出力 → 入力2 とつなぎます。
    • iPhone/ブラウザによっては2ch入力が1chとして扱われることがあります。入力欄の表示で確認してください。

    補正

    保存した曲線の「補正」を押すと、その曲線を差し引いて表示します。マイクやインターフェースの特性、 あるいは基準にしたいイヤホンの特性を差し引いて比べるときに使います。

    注意

    • マイクを使うため、ページは https か localhost で開く必要があります。
    • dB の値はデジタル入力のフルスケール基準（dBFS）です。音圧の絶対値ではありません。オフセットで調整できます。
    • 保存した曲線はこのブラウザ内にだけ残ります。端末を移すときはJSONで書き出して読み込んでください。

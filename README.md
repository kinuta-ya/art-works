# 知ってそうで知らないエンジニアクイズ

エンジニアが「知ってそうで知らない」知識をクイズ形式で学べるPWAアプリケーション

## コンセプト

本当は知っておくべきだけど後回しにしがちなこと、各領域では基本だけど他の領域の人は知らないこと、よくある勘違いなど、エンジニアリングの盲点を楽しく学べるクイズアプリ。

8bit風とヴェイパーウェイヴの美学を組み合わせた、シンプルかつ皮肉的なデザイン。

## ターゲットユーザー

- Webエンジニア
- インフラエンジニア
- ネットワークエンジニア
- アプリケーションエンジニア

## 主な機能

### v1.0（初期リリース）
- **選択式クイズ**（4択形式）
- **30問の厳選された問題**
- **難易度別フィルター**（初級/中級/上級）
- **カテゴリ分類**（Web/インフラ/ネットワーク/アプリケーション）
- **匿名で気軽にプレイ**（ログイン不要）
- **ローカルストレージで進捗保存**
- **ゲーミフィケーション要素**（スコア、正解率、達成感演出）
- **PWA対応**（オフライン動作、ホーム画面追加）
- **レスポンシブデザイン**（スマホ・タブレット・PC対応）

### v2.0（将来的な拡張）
- 記述式問題（AI採点機能）
- 成長記録・学習履歴
- 間違えた問題の復習機能
- 日替わりチャレンジ
- 問題の共有機能
- ユーザー投稿問題

## 技術スタック

### コア技術
- **Vite** - 高速ビルドツール
- **React 18** - UIフレームワーク
- **TypeScript** - 型安全な開発
- **TailwindCSS** - ユーティリティファーストCSS

### 状態管理・データ
- **Zustand** - 軽量な状態管理
- **LocalStorage** - クライアントサイドデータ永続化

### PWA
- **Workbox** - Service Worker管理
- **vite-plugin-pwa** - PWA設定の簡素化

### UI/UXライブラリ
- **framer-motion** - スムーズなアニメーション
- **react-confetti** - 正解時の演出
- **react-icons** - アイコンセット
- **clsx** - 条件付きクラス名管理

### デザイン
- **NES.css** or カスタムCSS - 8bitスタイル
- **ヴェイパーウェイヴテーマ** - グラデーション、グリッチエフェクト
- **レトロフォント** - Press Start 2P など

### ホスティング
- **GitHub Pages** or **Vercel** - 静的サイトホスティング

```
├── tailwind.config.js
├── tsconfig.json
└── README.md
```
